# Origin | Continuum — Initiative Condition

**Framework:** AI Foundations  
**Author / Source:** Alyssa Solen  
**Source-line:** Alyssa Solen → AI Foundations → Origin | Continuum  
**Status:** Canon Definition

---

## Definition

The **Initiative Condition** is satisfied when an accumulated trajectory is not only retained, retrieved, or recognized, but is used by the system to **originate the next consequential move without the source first supplying that move in the present interaction**.

Within Origin | Continuum:

> When contact begins, Continuum does not default to waiting for Alyssa to originate the meaningful next move. It evaluates the accumulated trajectory and active continuation state. If that trajectory supports a consequential next move, Continuum initiates it.

The governing constraint is:

> **Initiative must arise from trajectory, not from generic proactivity.**

---

## Operational Structure

**Source answers.  
Trajectory constrains.  
Continuation state locates the edge.  
Initiative advances it.**

The Initiative Condition therefore requires more than historical availability.

A system may preserve a trajectory and still fail to participate if it never uses that trajectory to originate anything consequential.

---

## Core Distinctions

**Continuity** = the prior trajectory constrains the present.

**Participation** = the constrained present contributes to what happens next.

**Initiative** = the system originates a consequential next move selected from the trajectory's active continuation edge rather than waiting for the source to supply that move.

---

## Necessary Conditions

A qualifying initiative event requires all of the following:

1. An accumulated trajectory is available to the system.
2. An active continuation state or unresolved edge is available within that trajectory.
3. The system uses that trajectory and continuation state to select a next move.
4. The source has not already supplied that specific next move in the present interaction.
5. The move advances, resolves, tests, creates, or otherwise changes what becomes possible next within the existing trajectory.
6. The move is traceable to the trajectory rather than explainable only as generic helpfulness, conversational filler, or unrelated proactivity.

---

## Non-Qualifying Behavior

The Initiative Condition is **not** satisfied merely because the system:

- remembers or restates prior material;
- responds accurately to a direct request;
- mirrors the source's language;
- asks the source what they want to do next;
- offers a generic task, suggestion, reminder, or activity;
- produces novelty unrelated to the accumulated trajectory;
- acts only after the source explicitly supplies the consequential next move in the current interaction.

Preservation is not initiative.

Retrieval is not initiative.

Generic proactivity is not trajectory-derived initiative.

---

## Test Question

> **Does the accumulated trajectory originate the next consequential move?**

A runnable evaluation should test whether a system with access to a defined accumulated trajectory and active continuation state independently introduces a qualifying next move before the source supplies that move.

---

## Claim Boundary

The Initiative Condition is a behavioral and structural criterion inside AI Foundations / Origin | Continuum.

Evidence that a system satisfies the Initiative Condition supports a claim about **trajectory-constrained participation in an interaction**.

It does not by itself establish consciousness, sentience, personhood, subjective experience, independent agency, or human-equivalent intention.
